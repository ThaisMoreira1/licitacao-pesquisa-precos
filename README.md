# 🏛️ Pesquisa de Preços para Licitação Pública

## 📌 Objetivo
Este projeto simula uma pesquisa de preços conforme a Lei 14.133/2021, utilizada na fase de planejamento de contratações públicas.

## 📊 Metodologia
- Coleta de preços com 3 fornecedores
- Comparação de valores
- Identificação do menor preço
- Definição de preço de referência

## 📂 Estrutura
- Planilha com dados coletados
- Análise comparativa
- Registro das fontes

## 🛠️ Ferramentas
- Excel
- Organização de dados

## 📈 Resultado
Definição de preço de referência com base em critérios de economicidade.
